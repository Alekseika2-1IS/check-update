# Правила работы с Check Update

Check Update — приложение для Windows 10/11 на C# и WPF (.NET Framework 4.8). Текущее состояние проекта описано в [PROJECT_STATUS.md](PROJECT_STATUS.md), команды сборки и описание поведения — в [README.md](README.md).

## Изменения и проверка

- Сохраняй русские подписи интерфейса и используй существующие стили WPF из `Theme.xaml`. При изменении интерфейса проверяй обычное и минимальное окно.
- Для изменений кода запускай `.\test.ps1 -Offline`. Если затронуты проверка или отображение обновлений, `.\test.ps1` дополнительно проверяет реальные каталоги. Оба режима тестирования обходятся без установки сторонних обновлений.
- Для изменений установщика запускай `.\test-installer.ps1`. Скрипт использует отдельную тестовую установку.

## Выпуск

- При подготовке новой версии согласуй номер в `Program.cs`, `setup.iss` и `RELEASE_NOTES.md`. Тег `vX.Y.Z` должен совпадать с версией приложения.
- [GitHub Actions](.github/workflows/release.yml) по тегу собирает и публикует установщик и переносимую версию с файлами SHA-256. После публикации проверь наличие обоих файлов и их контрольных сумм на странице выпуска.
- Коммить только файлы текущей задачи. Журналы, результаты локальных проверок и личные заметки остаются в рабочей копии.

Обновляй `PROJECT_STATUS.md` после выпуска или когда меняется следующая задача, чтобы работу можно было продолжить из репозитория.
