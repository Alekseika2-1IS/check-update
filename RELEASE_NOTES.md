## Check Update 0.12.2

- Переносимая версия и установщик публикуются с отдельными цифровыми подписями. Check Update проверяет подпись, версию и контрольную сумму перед применением будущих обновлений.

- Check Update отправляет параметры компьютера в каталог драйверов только после нажатия «Проверить каталог NVIDIA». Установленная версия определяется локально.
- Автообновление проверяет адрес точного выпуска и перенаправления GitHub. Контрольная сумма из выпуска используется и при скачивании, и при замене файла.
- WinGet запускается через системный псевдоним App Installer по полному пути.

Для обычной установки скачайте `Check-Update-Setup.exe`. Для запуска без установки по-прежнему доступен `Check-Update.exe`. Требуются Windows 10/11, .NET Framework 4.8 и WinGet.

Установка остаётся пользовательской, без автоматического повышения прав: выбирайте папку с доступом на запись для вашей учётной записи. Сборка не подписана сертификатом издателя; предупреждение Windows SmartScreen может по-прежнему появляться. Предыдущий файл после обновления сохраняется рядом с расширением `.previous` и удаляется при удалении программы. Локальные журналы и кэш загрузок сохраняются.
