## Check Update 0.11.1

- Блик покрывает всю площадь карточки версии и сводки обновлений, включая область вокруг кнопок.
- Убраны внутренние прямоугольные границы и длинная остановка блика. Скругления, отступы текста и работа кнопок сохранены.

- Новое графитовое оформление, голубые акценты и более просторный список программ.
- Основная кнопка установки перенесена в верхнюю сводку: количество выбранных программ видно прямо на кнопке. Она доступна и в разделе «Все программы».
- Световые переливы в сводке и карточке версии, блик при наведении на кнопки и навигацию. Анимации учитывают системную настройку Windows.
- Поиск, выделение, пропуск версий, история, журнал и подтверждение установки продолжают работать.

Для обычной установки скачайте `Check-Update-Setup.exe`. Для запуска без установки по-прежнему доступен `Check-Update.exe`. Требуются Windows 10/11, .NET Framework 4.8 и WinGet.

Установка остаётся пользовательской, без автоматического повышения прав: выбирайте папку с доступом на запись для вашей учётной записи. Сборка не подписана сертификатом издателя; предупреждение Windows SmartScreen может по-прежнему появляться. Предыдущий файл после обновления сохраняется рядом с расширением `.previous` и удаляется при удалении программы. Локальные журналы и кэш загрузок сохраняются.
