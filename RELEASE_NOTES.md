## Check Update 0.5.2

- Отдельный экран выбора папки установки.
- Путь можно ввести вручную или выбрать кнопкой «Обзор».
- При первой установке папку выбирает пользователь; при повторной показывается прежняя папка с возможностью её изменить.
- Перед установкой проверяется доступ для записи. Для защищённых или недоступных папок отображается понятное сообщение.
- Выбранный путь используется для файлов программы, ярлыков и удаления через Windows.

Поиск, установка обновлений, автоматическая сверка версий и обновление самого приложения сохранены.

Для обычной установки скачайте `Check-Update-Setup.exe`. Для запуска без установки по-прежнему доступен `Check-Update.exe`. Требуются Windows 10/11, .NET Framework 4.8 и WinGet.

Установка остаётся пользовательской, без автоматического повышения прав: выбирайте папку с доступом на запись для вашей учётной записи. Сборка не подписана сертификатом издателя; предупреждение Windows SmartScreen может по-прежнему появляться. Предыдущий файл после обновления сохраняется рядом с расширением `.previous` и удаляется при удалении программы. Локальные журналы и кэш загрузок сохраняются.
