## Check Update 0.3.0

- Собственная иконка приложения.
- Список установленных программ и доступных обновлений WinGet.
- Поиск, выбор обновлений и индикатор этапов установки.
- Автоматическая сверка списка после обновления программ.
- Проверка новых версий Check Update при запуске.
- Уведомление внизу окна, скачивание с GitHub, проверка SHA-256 и обновление после подтверждения перезапуска.

Скачайте `Check-Update.exe` из файлов этого выпуска и запустите. Требуются Windows 10/11, .NET Framework 4.8 и WinGet. Установка самого Check Update не требуется.

Сборка не подписана сертификатом издателя. Автоматического повышения прав нет: для замены файл приложения должен находиться в доступной пользователю для записи папке. Предыдущая версия сохраняется рядом с расширением `.previous`.
