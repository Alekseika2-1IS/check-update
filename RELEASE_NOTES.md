## Check Update 0.5.0

- Отдельный установщик с тёмной темой и иконкой Check Update.
- Установка только для текущего пользователя без запроса прав администратора.
- Ярлык в меню «Пуск» и необязательный ярлык на рабочем столе.
- Кнопка запуска приложения после установки.
- Удаление через список установленных приложений Windows.
- Обновление установленной копии из окна Check Update; версия в настройках Windows синхронизируется при запуске.

Поиск, установка обновлений, автоматическая сверка версий и обновление самого приложения сохранены.

Для обычной установки скачайте `Check-Update-Setup.exe`. Для запуска без установки по-прежнему доступен `Check-Update.exe`. Требуются Windows 10/11, .NET Framework 4.8 и WinGet.

Сборка не подписана сертификатом издателя; предупреждение Windows SmartScreen может по-прежнему появляться. Установщик не меняет настройки защиты Windows. Папка установки: `%LOCALAPPDATA%\Programs\Check Update`. Предыдущий файл после обновления сохраняется рядом с расширением `.previous` и удаляется при удалении программы. Локальные журналы и кэш загрузок сохраняются.
