## Check Update 0.4.0

- Новый тёмный интерфейс в цветах иконки: тёмно-синий, голубой и зелёный.
- Боковая панель с переключением между обновлениями и всеми программами.
- Счётчики найденных программ, доступных обновлений и выбранных установок.
- Оформленные строки списка, цветные статусы, новые кнопки и поле поиска.
- Отдельная карточка обновлений Check Update внизу слева.
- Подсказки до первой проверки и при пустом результате поиска.
- Кнопка установки активируется после выбора программ.

Поиск, установка обновлений, автоматическая сверка версий и обновление самого приложения сохранены.

Скачайте `Check-Update.exe` из файлов этого выпуска и запустите. Требуются Windows 10/11, .NET Framework 4.8 и WinGet. Установка самого Check Update не требуется.

Сборка не подписана сертификатом издателя. Автоматического повышения прав нет: для замены файл приложения должен находиться в доступной пользователю для записи папке. Предыдущая версия сохраняется рядом с расширением `.previous`.
