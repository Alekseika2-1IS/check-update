# Где остановились с Check Update

Последний выпуск — [Check Update 0.10.3](https://github.com/Alekseika2-1IS/check-update/releases/tag/v0.10.3). В двух полях поиска подсказки исчезают при фокусе, а текст начинается ближе к левому краю. Таблицы обрезаются по скруглённым рамкам, и полоса прокрутки начинается рядом с шапкой. Прошли 98 локальных проверок, и исправления проверены в установленной версии.

## Что подхватить

- Следующая правка пока не выбрана. Если появится новый баг, начни с воспроизведения в последнем выпуске и проверки затронутого экрана.
- Известный случай: GitHub может временно ограничить запросы проверки версии. Приложение показывает сообщение о лимите. Для ручного обновления доступен установщик на [странице последнего выпуска](https://github.com/Alekseika2-1IS/check-update/releases/latest).
